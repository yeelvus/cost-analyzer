一个入口跑通：**明细标准化 → 汇总分析 → 现金流 HTML → 分类持续学习**。

| 原脚本 | 新命令 | 作用 |
|--------|--------|------|
| `3_财务付款数据汇总台账.py` | `std` / `all` | raw → 按项目标准明细 + 一二级分类 |
| `4_财务付款数据_汇总分析.py` | `summary` / `all` | 总体汇总、按月宽表、科目宽表 |
| `5_财务付款项目现金流HTML.py` | `cashflow` / `all` | 项目累计现金流交互 HTML |
| `learn_classify` | `review` / `learn` / … | 待复核、学习、规则、迁移 |

## 2. 最常用命令

### 2.1 一键全流程（推荐每月出账后）

```bash
cd /Users/wyattsun/Desktop/code/12_财务数据/财务付款数据
python 财务付款一体化.py
```

直接运行即全流程，**不必再加 `all`**（`all` 仍兼容）。

等价于依次：

1. **std**：读 `A_财务付款_raw` → 写 `B_财务付款_std`
2. **summary**：读 std → 写汇总 Excel（两处）
3. **cashflow**：读 std → 写现金流 HTML

已有标准明细、只想刷新报表：

```bash
python 财务付款一体化.py --skip-std
```

学完分类后，汇总前先重刷一二级：

```bash
python 财务付款一体化.py --reclassify
# 或只重刷明细
python 财务付款一体化.py reclassify
python 财务付款一体化.py --skip-std
```

### 2.2 分步执行

```bash
python 财务付款一体化.py std          # 仅标准化
python 财务付款一体化.py summary      # 仅汇总 Excel
python 财务付款一体化.py cashflow     # 仅 HTML
python 财务付款一体化.py show-paths   # 看当前默认路径
```

### 2.3 自定义路径

```bash
python 财务付款一体化.py all \
  --raw-dir "/path/to/raw" \
  --std-dir "/path/to/std" \
  --sum-xlsx "/path/to/汇总.xlsx" \
  --cashflow-html "/path/to/现金流.html"
```

## 3. 分类学习闭环（如何越用越准）

### 步骤 A：导出待复核

```bash
python 财务付款一体化.py review
# 默认输出: learn_classify/data/待复核池.xlsx
```

打开 Excel，在 **`正确二级科目`** 列填写正确分类（可用显示名，如 `钢筋`、`场地清理费`，或稳定 ID `L2_mat_steel`）。  
`正确一级科目` 可选；填了二级会自动带出一级。

### 步骤 B：学习

```bash
python 财务付款一体化.py learn -i ./learn_classify/data/待复核池.xlsx
```

系统会：

- 写入 `memory.jsonl`（下次相同摘要直接命中）
- 追加 `corrections.jsonl`
- 更新供应商画像 `vendor_stats.json`

### 步骤 C：把纠错沉淀成规则（可选）

```bash
python 财务付款一体化.py suggest-rules
# 打开 规则建议.xlsx，把要通过的行 status 改为 approved
python 财务付款一体化.py approve-rules -i ./learn_classify/data/规则建议.xlsx
```

### 步骤 D：重刷明细 + 重出报表

```bash
python 财务付款一体化.py all --skip-std --reclassify
# 注意：--reclassify 会在 summary 前插入 reclassify；
# 若已 skip-std，实际是 reclassify → summary → cashflow
```

或：

```bash
python 财务付款一体化.py reclassify
python 财务付款一体化.py summary
python 财务付款一体化.py cashflow
```

### 步骤 E：健康度

```bash
python 财务付款一体化.py health
```

看：待复核率、命中层分布、一级/二级 top、「其他」是否过多。

### 单条调试

```bash
python 财务付款一体化.py classify --summary "预扣税" --subject "税款"
python 财务付款一体化.py classify --summary "角钢、工字钢" --subject "材料采购"
```

## 4. 一二级以后要改怎么快速转移

分类结果在库里存的是 **稳定 ID**（如 `L2_mat_steel`），不是会改的中文名。

1. 复制并编辑迁移文件，例如：  
   `learn_classify/data/migrations/example_v1_to_v1.1.json`
2. 常用字段：
   - `id_map`：旧 ID → 新 ID（记忆/规则一起转）
   - `rename`：只改显示名
   - `reparent`：二级换一级
   - `add_level2`：新增类
3. 执行：

```bash
python 财务付款一体化.py migrate \
  --map ./learn_classify/data/migrations/你的迁移.json \
  --with-reclassify
```

会自动备份 `data/`，更新 taxonomy/memory/rules，并重刷 `B_std` 显示名。

## 5. 命令一览

| 命令 | 说明 |
|------|------|
| （无参数 / `all`） | 全流程 3→4→5 |
| `std` | 仅标准化 |

| `show-paths` | 默认路径 |
| `help-guide` | 打印本说明 |

自定义全流程步骤：

```bash
python 财务付款一体化.py --steps std reclassify summary cashflow health
```
