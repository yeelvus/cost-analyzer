# 财务付款一体化 · 使用说明

一个入口覆盖两件事：**分类学习**（默认）与 **月结出账**（`all` / `month`）。

| 场景 | 命令 | 作用 |
|------|------|------|
| 改完分类总表后学习 | **无参数** / `apply-class` | 叶子变更 → memory + 重刷 B_std |
| 每月出账 / 刷新报表 | `all` 或 `month` | std → summary → cashflow |
| 原 3/4/5 分步 | `std` / `summary` / `cashflow` | 单步 |
| 分类维护 | `export-class` / `review` / `migrate` / `compact-memory` | 见下文 |

入口：

```bash
cd /Users/wyattsun/Desktop/code/12_财务数据/财务付款数据
python 财务付款一体化.py              # 默认 = apply-class（学总表 + 学习记录）
python 财务付款一体化.py apply-class  # 同上
python 财务付款一体化.py all          # 月结全流程 std → summary → cashflow
python 财务付款一体化.py month        # 同 all
python 财务付款一体化.py --help
python 财务付款一体化.py help-guide   # 打印本说明
```

> **注意：无参数 ≠ 全流程。** 出汇总 / HTML 请显式写 `all` 或 `month`。  
> **v2 起：业务逻辑全部在 `payment_hub/` 内**，不再依赖原 3/4/5 源码。

## 5. 分类学习闭环（如何越用越准）

### 步骤 A：导出待复核

```bash
python 财务付款一体化.py review
# 默认输出: learn_classify/data/待复核池.xlsx
```

打开 Excel，在 **`正确二级科目`** 列填写正确分类（可用显示名，如 `钢筋`、`场地清理费`，或稳定 ID `L2_mat_steel`）。  
`正确一级科目` 可选；填了二级会自动带出一级。

### 步骤 B：学习

```bash
python 财务付款一体化.py learn -i ./learn_classify/data/待复核池.xlsx
```

系统会：

- 写入 `memory.jsonl`（下次相同摘要直接命中）
- 追加 `corrections.jsonl`
- 更新供应商画像 `vendor_stats.json`

### 步骤 C：把纠错沉淀成规则（可选）

```bash
python 财务付款一体化.py suggest-rules
# 打开 规则建议.xlsx，把要通过的行 status 改为 approved
python 财务付款一体化.py approve-rules -i ./learn_classify/data/规则建议.xlsx
```

### 步骤 D：重刷明细 + 重出报表

```bash
python 财务付款一体化.py --skip-std --reclassify
# 实际顺序：reclassify → summary → cashflow
```

或：

```bash
python 财务付款一体化.py reclassify
python 财务付款一体化.py summary
python 财务付款一体化.py cashflow
```

### 步骤 E：健康度

```bash
python 财务付款一体化.py health
```

看：待复核率、命中层分布、一级/二级 top、「其他」是否过多。

### 单条调试

```bash
python 财务付款一体化.py classify --summary "预扣税" --subject "税款"
python 财务付款一体化.py classify --summary "角钢、工字钢" --subject "材料采购"
```

### 分类引擎分层（可解释）

| 层 | 来源 | 说明 |
|----|------|------|
| memory | `memory.jsonl` | 人工纠正过的摘要，最高优先 |
| rule_hi / rule | `rules.json` | 关键词 + priority（先高后低） |
| subject_map | `subject_map.json` | 原始财务科目名兜底 |
| vendor | `vendor_stats.json` | 同供应商历史众数 |
| pending | taxonomy 默认待复核 | **不再默认塞「管理费/其他」** |

## 6. 一二级以后要改怎么快速转移

分类结果在库里存的是 **稳定 ID**（如 `L2_mat_steel`），不是会改的中文名。

1. 复制并编辑迁移文件，例如：  
   `learn_classify/data/migrations/example_v1_to_v1.1.json`
2. 常用字段：
   - `id_map`：旧 ID → 新 ID（记忆/规则一起转）
   - `rename`：只改显示名
   - `reparent`：二级换一级
   - `add_level2`：新增类
3. 执行：

```bash
python 财务付款一体化.py migrate \
  --map ./learn_classify/data/migrations/你的迁移.json \
  --with-reclassify
```

会自动备份 `data/`，更新 taxonomy/memory/rules，并重刷 `B_std` 显示名。

| `suggest-rules` / `approve-rules` | 规则建议与合并 | corrections → rules |
| `migrate` | 分类体系迁移 | data + 可选 std |
| `classify` | 单条调试 | 只读 data |
| `health` | 健康度 | 读 std + data |
| `compact-memory` | 压缩 memory/corrections jsonl | data 知识库 |
| `dropdowns` | 给 B_std 一级/二级列批量加下拉 | 只改校验，不改数据 |
| `show-paths` | 默认路径 | — |
| `help-guide` | 打印本说明 | — |

### 一级 / 二级下拉（手动改分类）

`B_财务付款_std` 每个项目 Excel 的 **明细数据 / 明细数据_万泰铢** 中：

- **一级科目**：下拉选择 taxonomy 全部一级  
- **二级科目**：**随同行一级联动**（先选一级，二级只显示该类下的选项）  
- 选项来源：隐藏表 `_分类选项` + `learn_classify/data/taxonomy.json`  
- 允许手工输入列表外内容（不强制报错）

```bash

python 财务付款一体化.py dropdowns
```

之后每次 `std` / `reclassify` 会自动刷新下拉与选项表。

### 付款分类总表（确认学习 · 三级）

## 10. 排错速查

| 现象 | 处理 |
|------|------|
| 找不到项目匹配模块 | 确认 `code/0_项目基本信息/project_name_matcher.py` 存在 |
| 分类全是待复核 | 先 `review`+`learn` 补记忆；或补 `rules.json` / `subject_map.json` |
| 汇总项目数不对 | 看 `B_财务付款_std` 是否已用最新 `std` 生成 |
| 路径搞不清 | `python 财务付款一体化.py show-paths` |
| 改完类名结果还是旧的 | 用 `migrate` + `reclassify`，不要只改显示名却不刷 std |
| 直接运行却没有汇总/HTML | 无参数是 apply-class；出报表请用 `all` / `month` |
| memory.jsonl 很大 / 分类变慢 | `compact-memory --dry-run` 后执行 `compact-memory` |

有问题先跑：

```bash
python 财务付款一体化.py show-paths
python 财务付款一体化.py classify --summary "测试"
python 财务付款一体化.py compact-memory --dry-run
```
