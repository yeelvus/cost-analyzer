# 预算 vs 过程 · 人材机结构对比 — 使用说明

## 一句话

把 **广联达预算（人/材/机）** 和 **过程台账（人工费 + 采购 + 商混 + 机具）** 拉到同一项目、同一单位（万泰铢），每月重跑即可更新数据与看板。

## 每月怎么跑

```bash
cd /Users/wyattsun/Desktop/code

# 1）确保各领域本月 std/sum 已更新（采购、机具、人工、商混、预算）
# 2）生成对比 Excel + HTML
python3 build_budget_vs_process.py --month 2026年06月

# 人民币预算项目：调整汇率后重跑
python3 build_budget_vs_process.py --fx 4.85 --month 2026年06月
```

汇率也可改配置文件后直接重跑：

`Desktop/code/common/budget_vs_process_config.json`

```json
{
  "fx_cny_to_thb": 4.9,
  "warn_exec_ratio": 1.15,
  "danger_exec_ratio": 1.30,
  "warn_struct_gap_pct": 8.0
}
```

## 输出位置

| 文件 | 说明 |
|------|------|
| `01成本统计/Z_report/预算vs过程_人材机对比_最新.html` | 看板（每月覆盖） |
| `01成本统计/Z_report/预算vs过程_人材机对比_最新.xlsx` | 明细 + 组合结构（每月覆盖） |
| `…_YYYYMMDD_HHMMSS.xlsx / .html` | 历史归档，不覆盖 |

Excel 含 sheet：`项目对比明细`、`组合结构`、`双边齐全项目`、`生成信息`。

## 口径

| 维度 | 预算 | 过程 |
|------|------|------|
| 人 | 广联达 `人_明细` | `人工费汇总.xlsx` 总人工费 |
| 材 | 广联达 `材类明细` | 采购台账总金额 + 搅拌站商混 |
| 机 | 广联达 `设机_明细` | 机具租赁费用合计 |
| 单位 | CNY×汇率或 THB → 万泰铢 | 泰铢 → 万泰铢 |

**执行率** = 过程 / 预算。  
**结构差** = 过程占比 − 预算占比（百分点）。

## 注意

1. 过程「材」含采购+商混，与预算材类并非逐项一一对应，适合结构与总量监控，不宜当精确结算。  
2. 项目名称不一致时依赖 `project_name_matcher`；仍对不齐会出现「仅预算 / 仅过程」。  
3. 预算更新：先跑 `3_预算部分代码/广联达预算人材机文件统计.py`，再跑本脚本。  
4. 与全过程看板联看：`Z_report/全过程成本分析看板_最新.html` 底部已链到本页。
