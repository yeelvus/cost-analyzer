## 一、整体在做什么

把各项目月度采购 Excel，整理成：

1. **全量纯合并**（不改内容）  
2. **标准化汇总**（规格/单位规范化 + 原始对照 + 分类项目汇总）  
3. **按项目拆分**的单项目采购文件  

供成本统计、价格分析、项目对账使用。

### 数据流（前缀 A→F 与步骤顺序一致）

```text
A_采购部采购台账_raw          月度原始
    │  01 重命名（手动）
    │  02 月度去重（手动）
    ▼
B_采购部采购台账_extract      每项目 1 份去重台账
    │  03 格式标准化（手动）
    ▼
C_采购部采购台账_std           *_processed.xlsx
    │
    ├─【默认】04a ──────────► D_raw_sum/采购部采购台账_raw_sum.xlsx
    │                              │
    │                              ├─【默认】04b ─► E_sum/采购部采购台账_std_sum.xlsx
    │                              │
    │                              └─【默认】06 ──► F_std_split/{编码}_{名称}_采购数据.xlsx
    │                                                 （06 默认读 E_sum/std_sum）
    └─（04b 的 std_sum 内含：合并数据/项目汇总/项目金额汇总/采购总金额）
```

## 三、流水线各脚本功能

| 编号 | 文件 | 默认？ | 功能 |
|------|------|--------|------|
| **01** | `01_重命名月度文件.py` | 手动 | 按月份文件夹规范文件名：`{项目}_{YYYY年MM月}_公司采购台账.xlsx` |
| **02** | `02_月度去重提取.py` | 手动 | 对比上月，剔除未更新台账；每项目保留 1 份 → `B_采购部采购台账_extract` |
| **03** | `03_excel格式标准化.py` | 手动 | 列映射、项目匹配、日期 → `C_std/*_processed.xlsx`；支持 `--no-prompt` 不弹窗 |
| **04a** | `04a_raw_sum纯合并.py` | **默认** | C_std 直接拼表，不改内容 → `D_raw_sum/采购部采购台账_raw_sum.xlsx` |
| **04b** | `04b_std_sum汇总.py` | **默认** | 以 **D_raw_sum** 为源：内容标准化 + 原始对照 + 单位转换 + 非泰铢汇率换算 + 分类「项目汇总」→ `E_sum/采购部采购台账_std_sum.xlsx` |
| **05** | `05_分类汇总刷新.py` | 可选 | 仅刷新 std_sum 内「项目汇总」sheet（日常已由 04b 写入） |
| **06** | `06_按项目拆分.py` | **默认** | 按项目拆 **E_sum/std_sum**（含汇率换算与绿色填充）→ `F_std_split/{编码}_{名称}_采购数据.xlsx` |

### std_sum.xlsx 内 sheet

| Sheet | 内容 |
|--------|------|
| **合并数据** | 首列**序号**；原始名称/规格/单位；转换单位/计算数量；标准化后列 |
| **项目汇总** | 按项目×材料大类（钢筋/砂浆水泥/砖/模板/碎石/其他）数量与金额 |
| **项目金额汇总** | 项目总采购金额 |
| **采购总金额** | 项目 × 月份 金额宽表 |

（不再生成「分类合计」「分类明细」，也不再单独生成 `项目采购分类汇总.xlsx`。）

## 四、其它模块功能

| 目录 | 作用 |
|------|------|
| **规格标准化/** | 桩、钢筋（含 DB40T/SR24/圆钢等）、网片、砖、模板、碎石、砂浆等规格规范化；`0_统一标准化流水线` 可单独串行跑 |

| **分析看板/** | 钢筋价格趋势、桩成本看板；读 E_sum/std_sum |
| **工具/** | 查询系统等；`工具/归档/` 为历史一次性分析脚本 |

## 五、数据目录约定（A→F）

| 目录 | 含义 | 主要产物 |
|------|------|----------|
| `A_采购部采购台账_raw` | 月度原始 | 各月项目 Excel |

| `Z_report/C_采购数据分析` | 分析输出 | 价格/桩看板 Excel+HTML |

## 六、用法

```bash
cd /Users/wyattsun/Desktop/code/9_采购数据

# 看结构与路径
PYTHONPATH=.. python3 0_run_采购全流程.py --tree

# 日常默认：04a 纯合并 → 04b std_sum → 06 按项目拆分
PYTHONPATH=.. python3 0_run_采购全流程.py

# 只要汇总、不拆分
PYTHONPATH=.. python3 0_run_采购全流程.py --no-split

# raw_sum 已存在，跳过 04a
PYTHONPATH=.. python3 0_run_采购全流程.py --no-raw-sum

# 只拆分
PYTHONPATH=.. python3 0_run_采购全流程.py --only 06

# 从重命名到拆分一次跑完
PYTHONPATH=.. python3 0_run_采购全流程.py --with-prep

# 单步
PYTHONPATH=..:. python3 流水线/04a_raw_sum纯合并.py
PYTHONPATH=..:. python3 流水线/04b_std_sum汇总.py
PYTHONPATH=..:. python3 流水线/06_按项目拆分.py --clear
# 默认读 E_sum/采购部采购台账_std_sum.xlsx；旧源可用 --from-raw-sum
```
